# web-vitals para actuaria.com

Copia de [web-vitals](https://github.com/GoogleChrome/web-vitals) 6.2.3 (versión con atribución, IIFE), bajada del
registro de npm con su integridad sha512 verificada. La carga la etiqueta «HTML - Web Vitals INP» de Tag Manager
(GTM-WVB8ND3W) con SRI, para medir el INP de las visitas reales y enviar a GA4 qué elemento y qué script lo causan.
